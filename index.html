Three instruments, one surface

Pool the work. Keep the keys. Route the swap.

RUPool-class monitoring is the first third. The other two — a vault you control and a swap that never custodians coins — are what turn a dashboard into a stack.

01

Multi-currency pool

Point ASICs or GPU rigs at Orion stratum. Shares settle under FPPS. BTC, merged LTC/DOGE, and KAS in one login. Workers, 24h hashrate, and payouts live in the same console the reference app already trained miners to expect.

02

Self-custody wallet

The pool pays an address you generate here. The seed is created in the browser, stored only in this device’s local vault, and can be exported or wiped. Orion never holds a hot wallet of user funds.

03

No-KYC swap

Not a hosted order book. A router over non-custodial rails (THORChain-class cross-chain, plus same-chain DEX where it exists). You sign. Liquidity lives in public protocols. No account, no deposit book, no identity file.

Path

Connect hardware. Get paid to your vault.

01

Create the vault

Generate a 12-word seed on-device. Write it down. Orion stores an encrypted copy only in this browser.

02

Point the miner

Worker name is vault-id.rig-01. Password can be x. Hashrate should appear as shares, not as a promise.

03

Pay out and swap

Daily threshold to your receive address. Swap from the same screen if you want stables or another coin.

What this is

A working surface. Not a live pool.

Built in this pass

Marketing site, full app shell, pool console, worker list, local vault with seed generate/import/wipe, receive addresses, send form, swap quote + sign flow, payouts ledger, settings. State persists in localStorage.

Not claimed as live

No real stratum servers, no FPPS treasury, no broadcast of transactions, no licensed exchange. A US-operated custodial book with no KYC is not the design. The swap is a router sketch over public non-custodial protocols.
