Operator pack · 2026-09-07

How to stand this up without lying about it.

The app is a desk. A live pool is a treasury plus stratum. A no-KYC convert is a router, not a book. This page is the shortlist and the float math.

1. Stratum vendors

Do not write a stratum server. Buy or fork something that already speaks ASICs.

OptionRoleAlgo fitVerdict
ckpool (Kolivas) BTC pool / proxy / passthrough SHA-256. SV2 in source as of Jul 2026 (HAVE_SV2). Default BTC path. GPLv3. 0.5% default dev donation in pool mode — read the license and config before production.
SRI / stratum-mining sv2-apps Stratum V2 libraries and reference apps SHA-256 Use when you want job declaration and encrypted transport. Most Antminer stock firmware is still V1 — pair with a V1→V2 proxy (ckproxy or SRI translation proxy).
mkpool Solo pool, V1 + SV2 + TLS SHA-256 solo Useful as a solo sidecar, not as the FPPS book.
Braidpool Decentralized pool research SHA-256 Watch. Not an ops default in 2026.
Litecoin / Scrypt stack Merge LTC+DOGE (+ BELLS/LKY if you list them) Scrypt Run a separate Scrypt stratum + litecoind/dogecoind (or a merge-aware fork). Do not stretch ckpool into Scrypt.
Kaspa stratum kHeavyHash KAS Separate daemon and stratum. PPLNS until that book has its own float table.

2. FPPS float

FPPS is insurance. You pay shares whether you find the block. Network snapshot used in the workbook: ~930.7 EH/s, subsidy 3.125 BTC, fee proxy 0.10 BTC, BTC ~$79,110, 14-day horizon, 1% pool fee, z = 2.33.

Book sizeE[blocks / 14d]P(zero in 14d)Offer FPPS?
100 TH/s~0.0002~100%No. PPLNS or don’t take public hash.
1 PH/s~0.002~100%No.
10 PH/s~0.02~98%No.
100 PH/s~0.22~80%Only with an outside backstop.
1 EH/s~2.2~11%Conditional. Fund the spreadsheet line.
10 EH/s~22~0%Standard FPPS if treasury is funded.

Daily liability ≈ (H_pool / H_net) × 144 × (3.125 + F) × (1 − fee). Recommended float ≈ 14 days of that liability + 1 day of share lag + z√λ × block value. Workbook: ops/orion-fpps-float.xlsx — yellow cells are inputs.

Hot wallet ≤ 2 days of liability. Cold / multisig holds the rest. User seeds never land on pool boxes.

3. Swap rails (no hosted book)

RailJobKYC shape

Same-chain DEXOnly after an asset is wrapped onto a smart-contract chainFine for the second hop, not for mined BTC by itself.
Hosted instant-exchange APITempting UXReject as the core. You inherit their license problems and their freeze book.

4. Vault libraries (when leaving the demo wordlist)

Replace the prototype list with audited primitives only: @scure/bip39 + @scure/bip32 (Paul Miller / noble), Bitcoin addresses via a maintained bitcoinjs or rust-bitcoin binding, Litecoin/Dogecoin/Kaspa derivation behind explicit coin-type paths. Do not ship a homemade RNG wordlist to mainnet. The current app is labeled prototype for that reason.

5. Legal posture (Colorado operator)

A pool that pays on-chain to miner-controlled addresses is a service. A hosted convert with balances and no KYC is a money-transmitter shape. Keep the desk as a router. Publish TOS, fee, scheme, and geo policy before inviting hashrate. This page is not legal advice.
